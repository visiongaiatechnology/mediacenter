## Введение и философия

Современное программное обеспечение все чаще навязывает облачную зависимость: требует постоянного подключения к сети, подписок и передачи личных данных на удаленные серверы телеметрии.

**VGT Mediacenter** решительно отвергает этот подход. Это **автономная локальная рабочая станция**, содержащая 40 инструментов промышленного уровня для криптографии, цифровой криминалистики документов, анализа аудио, разработки, вычислений и бескомпромиссной защиты конфиденциальности.

### Архитектурные гарантии:
* **Zero Cloud:** Никаких серверов, маяков слежения, аналитических пингов и удаленных API-вызовов.
* **100% In-Memory обработка:** Файлы, помещаемые в инструменты, никогда не покидают локальную оперативную память устройства. Вычисление хешей, цензурирование PDF и аудиообработка выполняются в оперативной памяти с помощью HTML5 Web APIs и WebAssembly.
* **Детерминированная переносимость:** Одинаковый интерфейс и функционал как в виде нативного безрамочного десктоп-приложения для Windows и Linux, так и в виде защищенного шорткода WordPress для внутренних сетей.

---

## Ключевые особенности

* **Интерфейс Glass 2100 Sovereign:** Фирменный стиль Obsidian Glass с аппаратным размытием фона (`blur(28px)`), чистым фоном без навязчивых сеток и мягким бирюзовым свечением.
* **Нативное управление окном:** Кастомные элементы управления (свернуть, развернуть/восстановить, закрыть), интегрированные с Wails v2 и системными оконными менеджерами Windows и Linux.
* **Мгновенный запуск (доли секунды):** Скомпилированные в памяти манифесты исключают задержки протокола `file://` и CORS, позволяя станции запускаться быстрее чем за 600 мс.
* **Полная поддержка 8 языков:** Deutsch, English, Русский, Español, Italiano, 简体中文, 日本語 и Français — сквозная и непрерывная во всех 40 приложениях.

## Установка и запуск

### Windows Desktop
Требуется Windows 10/11 (64-bit). Используется системная среда выполнения Microsoft Edge WebView2 Evergreen.
1. Скачайте `VGT-Mediacenter-Supreme.exe` из раздела релизов.
2. Запустите двойным кликом. Права администратора и установка не требуются.
3. *Альтернатива:* Запуск через скрипт `launch-windows.bat`.

### Linux Desktop
Совместимо с Ubuntu 20.04+, Debian 11+, Fedora 38+, Arch Linux, Linux Mint (x86_64).
1. Скачайте архив `VGT-Mediacenter-Supreme-Linux-x86_64.tar.gz`.
2. Распакуйте архив:
   ```bash
   tar -xzf VGT-Mediacenter-Supreme-Linux-x86_64.tar.gz
   cd VGT-Mediacenter-Supreme-Linux
   ```
3. Запустите через скрипт:
   ```bash
   ./launch-linux.sh
   # Либо запустите бинарный файл напрямую:
   ./VGT-Mediacenter-Supreme
   ```
4. *(Опционально)* Интеграция в системное меню:
   ```bash
   cp vgt-mediacenter.desktop ~/.local/share/applications/
   ```

### Плагин для WordPress
Совместимо с WordPress 6.0+ и PHP 8.1+.
1. Скопируйте каталог `wordpress/` в вашу директорию плагинов WordPress: `wp-content/plugins/vgt-mediacenter/`.
2. Активируйте плагин в разделе **Панель управления WordPress $\to$ Плагины**.
3. Вставьте полную автономную станцию на любую страницу или запись с помощью шорткода:
   ```text
   [vgt_mediacenter]
   ```

## Многоязычная архитектура (i18n)

VGT Mediacenter включает собственную локальную систему перевода ([i18n.js](desktop/frontend/i18n.js)):
* **Модальное окно первого запуска:** При первом открытии пользователю предлагается выбрать предпочитаемый язык интерфейса.
* **Переключатель в шапке:** Нажатием кнопки `🌐 [LANG]` в верхней панели навигации язык можно переключить в любой момент.
* **Нулевая задержка:** Все переводы для 40 инструментов, категорий и системных уведомлений хранятся в оперативной памяти и переключаются мгновенно без перезагрузки интерфейса.

## Безопасность и принцип Zero-Trust

* **Content Security Policy (CSP):** Приложение исполняется с жесткими ограничениями CSP; любые исходящие сетевые подключения к внешним доменам заблокированы.
* **Zero Telemetry / No Phone-Home:** Никаких счетчиков Google Analytics, трекеров ошибок Sentry или скрытых запросов.
* **Защита DOM-дерева:** Любая вставка разметки проходит обязательную фильтрацию и санитайзинг SVG/HTML для предотвращения DOM-XSS уязвимостей.
