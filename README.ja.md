## はじめに ＆ 開発理念

現代のソフトウェア環境はユーザーをクラウドの独占状態へと囲い込み、常時インターネット接続、継続課金サブスクリプション、そしてプライベートな個人データの遠隔テレメトリサーバへの流出を余儀なくさせています。

**VGT Mediacenter** はこの構造を根本から拒絶します。本プロダクトは、暗号工学、文書フォレンジック、音響解析、ソフトウェア開発、精密演算、そして強固なプライバシー保護のための40種の産業水準ツールを搭載した**完全ローカル完結型ソブリン・ワークステーション**です。

### アーキテクチャの厳格な保証：
* **ゼロクラウド (Zero Cloud):** サーバ通信なし、追跡ビーコンなし、解析用ピングなし、リモートAPIコールなし。
* **100% インメモリ処理:** 各ツールに投入されたファイルはお使いの端末のRAMから一切外部へ出ません。ハッシュ計算、PDF黒塗り、音声処理はHTML5 Web APIおよびWebAssemblyを活用してローカルCPU/GPU上でのみ完結します。
* **決定論的ポータビリティ:** WindowsおよびLinux上でのフレームレスなネイティブ・デスクトップアプリとしても、イントラネット環境での堅牢なWordPressショートコードとしても、全く同一の快適な体験を提供します。

## 主要機能・特徴

* **Glass 2100 Sovereign インターフェース:** ハードウェアによる背景ぼかし (`blur(28px)`) を採用した独自開発の黒曜石グラス (Obsidian Glass) スタイル。煩わしい格子状の背景を排除し、洗練されたシアンの光彩を放ちます。
* **フレームレスなOSネイティブ操作系:** 最小化・最大化/元に戻す・閉じるボタンを独自描画し、Wails v2および各種OSのウィンドウマネージャと完全に連携。
* **1秒未満の瞬間起動:** インメモリ上に事前コンパイルされたマニフェストにより、`file://` プロトコルによるCORS制約を回避し、600ミリ秒未満での超高速起動を実現。
* **全8言語の完全サポート:** ドイツ語、英語、ロシア語、スペイン語、イタリア語、中国語（簡体字）、日本語、フランス語の全言語を40種すべてのツールで一貫してサポート。

## インストールと実行方法

### Windows デスクトップ
動作要件: Windows 10 / Windows 11 (64-bit)。OS標準の Microsoft Edge WebView2 Evergreen ランタイムを利用。
1. Releasesから最新の `VGT-Mediacenter-Supreme.exe` をダウンロード。
2. ダブルクリックして起動。インストーラーや管理者権限は不要です。
3. *代替起動方法:* ルート直下の `launch-windows.bat` を実行。

### Linux デスクトップ
Ubuntu 20.04+、Debian 11+、Fedora 38+、Arch Linux、Linux Mint (x86_64) など主要ディストリビューションに対応。
1. `VGT-Mediacenter-Supreme-Linux-x86_64.tar.gz` をダウンロード。
2. アーカイブを展開:
   ```bash
   tar -xzf VGT-Mediacenter-Supreme-Linux-x86_64.tar.gz
   cd VGT-Mediacenter-Supreme-Linux
   ```
3. 起動スクリプトを実行:
   ```bash
   ./launch-linux.sh
   # またはバイナリを直接実行:
   ./VGT-Mediacenter-Supreme
   ```
4. *(任意)* デスクトップ環境へのメニュー登録:
   ```bash
   cp vgt-mediacenter.desktop ~/.local/share/applications/
   ```

### WordPress プラグイン運用
WordPress 6.0以上およびPHP 8.1以上に対応。
1. リポジトリ内の `wordpress/` ディレクトリをプラグインフォルダへ配置: `wp-content/plugins/vgt-mediacenter/`。
2. **WordPress管理画面 $\to$ プラグイン** より有効化。
3. 任意の固定ページまたは投稿に以下のショートコードを記述するだけで全ワークステーションが利用可能:
   ```text
   [vgt_mediacenter]
   ```

## 多言語統合アーキテクチャ (i18n)

VGT Mediacenterは、完全インメモリ駆動の国際化エンジンを搭載しています ([i18n.js](desktop/frontend/i18n.js)):
* **初回起動モーダル:** 初めてアプリを起動した際に、希望する表示言語を選択するダイアログが前面に表示されます。
* **ヘッダー切替ボタン:** 画面上部バーの `🌐 [LANG]` ボタンから、作業中いつでも瞬時に言語を切り替えることができます。
* **ゼロレイテンシ:** 全40ツールの名称、解説、バッジ、システムメッセージはRAM上に常駐しており、ページのリロードを挟むことなく0ミリ秒で即座に反映されます。

## セキュリティとゼロトラスト原則

* **コンテンツセキュリティポリシー (CSP):** 厳格なCSP方針のもとで動作し、未許可の外部通信経路は完全に遮断されています。
* **ゼロテレメトリ (No Telemetry):** Google Analytics、Sentry、トラッキング用ビーコンは一切組み込まれていません。
* **DOMサニタイズ処理:** 動的に挿入されるHTMLおよびSVGはすべて安全なエスケープおよびサニタイズ処理を通過し、DOM-XSSの脅威を完全に排除します。
